# База данных «Сеть пекарен»

## Описание
Реляционная база данных для автоматизации полного цикла работы сети пекарен:
от закупки ингредиентов до продажи готовой продукции клиентам.

## Технические характеристики
- **СУБД:** PostgreSQL 18+
- **Количество таблиц:** 33 + 1 представление
- **Бизнес-блоков:** 6
- **ENUM-типов:** 9
- **Индексов:** 55+

## Возможности
- Полный учёт остатков с контролем сроков годности
- Система лояльности с многоуровневыми картами
- Контроль медицинских книжек сотрудников
- Аналитическое представление `v_sales_full` для быстрой статистики продаж

## Как развернуть БД
# 1. Создать базу данных
createdb -U postgres bakery_chain

# 2. Развернуть схему (человекочитаемая версия)
psql -U postgres -d bakery_chain -f schema.sql
# ИЛИ если нужна точная копия из дампа:
# psql -U postgres -d bakery_chain -f dump_schema.sql

# 3. Загрузить тестовые данные
psql -U postgres -d bakery_chain -f data_insertion.sql

# 4. Запустить тестовые запросы
psql -U postgres -d bakery_chain -f test_queries.sql
